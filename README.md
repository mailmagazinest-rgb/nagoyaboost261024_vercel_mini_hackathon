# 愛知の空

愛知県内9地域の現在の天気、時間ごとの予報、最高・最低気温、降水確率、風速、湿度、日の出・日の入りを表示する SvelteKit アプリです。

天気データは [Open-Meteo](https://open-meteo.com/) の Forecast API から取得します。地域を選ぶと、その地域の予報に切り替わります。

## 対象地域

名古屋市、豊田市、岡崎市、豊橋市、一宮市、西尾市、半田市、蒲郡市、新城市

## 開発

```bash
npm install
npm run dev
```

## デプロイ

このリポジトリは Vercel に接続されています。GitHub の `main` ブランチに変更を反映すると、自動でビルドとデプロイが始まります。
